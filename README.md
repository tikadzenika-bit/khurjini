# Khurjini (ხურჯინი) — დემო საიტი

ერთგვერდიანი საიტი მაღაზია „ხურჯინისთვის“ (ქართული სანელებლები და ნატურალური პროდუქტები ძველ თბილისში). ენები: English (ძირითადი), ქართული, Русский. ეს არის **დემო / კონცეფცია**: ფოტოები ნიმუშია, ფასები ჯერ არ წერია.

## როგორ გავხსნა

`index.html`-ზე ორჯერ დააწკაპუნე — გაიხსნება ბრაუზერში. ინტერნეტი საჭიროა მხოლოდ ფონტებისა და რუკისთვის.

ენის პირდაპირი ბმული: მისამართის ბოლოს დაამატე `?lang=ka` ან `?lang=ru`.

## რა სად არის

| ფაილი | რა არის |
| --- | --- |
| `index.html` | გვერდის ჩონჩხი და SEO (სათაური, აღწერა, გაზიარების სურათი, LocalBusiness სქემა) |
| `css/style.css` | იერი. ფერები და ფონტები ფაილის თავში, `:root`-ში |
| `js/main.js` | **მთელი ტექსტი სამ ენაზე** (`TEXT`), კატეგორიები (`CATEGORIES`), სანელებლები (`SPICES`), ნაკრებები (`GIFTS`), ნომერი და საათები (`CONTACT`) |
| `images/` | სურათები. რომელი ფოტოა საჭირო — `images/README.md` |

## რა უნდა შეცვალონ მფლობელებმა

1. **ფოტოები** — ახლა ყველა სურათი დახატული ნიმუშია წარწერით „ნიმუში · placeholder“. ნამდვილი ფოტო იმავე სახელით ჩააგდე `images/`-ში (მაგ. `spices.jpg`) და საიტზე თავისით შეიცვლება. სია: `images/README.md`.
2. **ფასები** — ნაკრებებზე ახლა წერია „ფასი: მოგვწერე WhatsApp-ზე“. ნამდვილი ფასი: `js/main.js` → `GIFTS` → `price: null` შეცვალე რიცხვით, მაგ. `price: 45`.
3. **ნაკრებების შემადგენლობა და სახელები** — `GIFTS`-ში. ახლანდელი სამი ნაკრები მაგალითია.
4. **დაარსების წელი** — „2016 წლიდან“ გვერდზე განზრახ არ წერია. დადასტურების შემდეგ დაამატე ისტორიის ტექსტში (`TEXT` → `story.p1`, სამივე ენაზე) და `index.html`-ის სქემაში (`"foundingDate": "2016"`).
5. **ნამდვილი შეფასებები** — სექცია „რას ამბობენ სტუმრები“ ახლა ცარიელი ადგილია. Google-ის ნამდვილი შეფასებები ჩაისმება მფლობელების თანხმობით.
6. **საზღვარგარეთ გაგზავნა** — ფუტერის წინადადება (`TEXT` → `foot.ship`): რომელ ქვეყნებში, რა ვადაში, რა ფასად.
7. **სანელებლების გზამკვლევი** — ბოლო ორი (ყვითელი ყვავილი, ხმელი ქინძი) ჩვენი დამატებულია; დაადასტურეთ, რომ მაღაზიაში არის, ან შეცვალეთ `SPICES`-ში.

ყველა ასეთი ადგილი კოდში მონიშნულია სიტყვით `TODO` (მოძებნე Ctrl+F-ით).

## დემო ბანერის მოხსნა

`index.html`-ში წაშალე ერთი ხაზი, რომელიც ასე იწყება: `<p class="demo-banner"`.

## GitHub-ზე ატვირთვა და GitHub Pages

1. შედი [github.com](https://github.com)-ზე შენი ანგარიშით. ზემოთ მარჯვნივ **+ → New repository**.
2. **Repository name**: `khurjini`. აირჩიე **Public**. დააჭირე **Create repository**.
3. გახსნილ გვერდზე დააჭირე **uploading an existing file**.
4. კომპიუტერიდან გადაათრიე ამ საქაღალდის მთელი შიგთავსი: `index.html`, `README.md` და საქაღალდეები `css`, `js`, `images`. დააჭირე **Commit changes**.
5. რეპოზიტორიაში გახსენი **Settings → Pages**.
6. **Source**: `Deploy from a branch`. **Branch**: `main` და `/ (root)`. დააჭირე **Save**.
7. 1–2 წუთში საიტი გაიხსნება მისამართზე `https://შენი-სახელი.github.io/khurjini/`.

### გაზიარების სურათი (WhatsApp-ის პრევიუ)

`index.html`-ის თავში რამდენიმე ადგილას წერია მისამართი `https://tikadzenika-bit.github.io/khurjini/` (`canonical`, `og:url`, `og:image` და სქემის `image`, `url`). თუ საიტი სხვა მისამართზე გამოქვეყნდა, ეს მისამართი ყველგან შეცვალე ნამდვილით — სხვაგვარად WhatsApp-ში ბმულს სურათი არ გამოუჩნდება.

## საკუთარი დომენის მიბმა (მოგვიანებით)

1. იყიდე დომენი (მაგ. `khurjini.ge`) რეგისტრატორთან.
2. საიტის საქაღალდეში (იქ, სადაც `index.html` დევს) შექმენი ფაილი სახელით `CNAME` (გაფართოების გარეშე), შიგნით ერთი ხაზი: `khurjini.ge`. ატვირთე GitHub-ზე.
3. რეგისტრატორის DNS პარამეტრებში დაამატე ჩანაწერები:

   | ტიპი | სახელი | მნიშვნელობა |
   | --- | --- | --- |
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |
   | CNAME | www | `შენი-სახელი.github.io` |

4. GitHub-ზე **Settings → Pages → Custom domain**: ჩაწერე დომენი, **Save**. რამდენიმე საათში, როცა შემოწმება დასრულდება, მონიშნე **Enforce HTTPS**.
5. `index.html`-ში ძველი მისამართი ყველგან შეცვალე ახალი დომენით.

## ტექნიკური შენიშვნები

- უბრალო HTML + CSS + JavaScript, აწყობის ნაბიჯი არ სჭირდება.
- „ხურჯინში ჩადება“: სტუმარი ირჩევს რამდენიმე ნივთს და ქვედა ღილაკით ერთ WhatsApp-შეტყობინებად აგზავნის მთელ სიას.
- „ახლა ღიაა / დაკეტილია“ ითვლება თბილისის დროით (`CONTACT.opens`, `CONTACT.closes`).
- შემოწმებულია 1440, 768 და 390 px სიგანეზე, სამივე ენაზე. ნამდვილ ტელეფონზე ჯერ არ შემოწმებულა.
